## Resource Generation

Main UI resource generation:

```powershell
powershell -ExecutionPolicy Bypass -File scripts\generate-assets.ps1 -BackgroundSource assets\gt.r\bg.png -IconSource assets\gt.r\icon.png
```

This script:

- Generates UI assets such as buttons, background, category icons, and sport icons.
- Calls `scripts/generate-b-style-animations.ps1`.
- Outputs both `assets/gt.r` and `assets/gt.s`.

Generate B-style animation frames only:

```powershell
powershell -ExecutionPolicy Bypass -File scripts\generate-b-style-animations.ps1
```

Important generator contracts:

- Single-side exercises generate `_left` and `_right` mirrored animation folders.
- `generate-b-style-animations.ps1` normalizes visible sprite scale using alpha bounds so different poses do not appear wildly different in size.
- Select icons must be generated at the same size as their layout boxes:
  - Round category icons: `32x32`
  - Round sport icons: `42x42`
  - Square category icons: `24x24`
  - Square sport icons: `38x38`

## Bugs Already Fixed

### Zepp Alignment Constants

Do not use bare numeric alignment values in layout files:

```js
align_h: 1
align_v: 2
```

Bare numbers caused centered text to render left- or right-aligned in the simulator. Use Zepp named constants:

```js
import { align } from "@zos/ui";

align_h: align.CENTER_H
align_v: align.CENTER_V
align_h: align.LEFT
align_v: align.TOP
```

Regression test:

```text
test/layout-alignment.test.mjs
```

### Select Activity Text Overlap

`page/select/select.js` must preserve relative y offsets from the layout styles:

```js
y: itemY + Styles.ITEM_TEXT_STYLE.y
y: itemY + Styles.ITEM_SUB_STYLE.y
y: itemY + Styles.RECOMMEND_TAG_STYLE.y
```

Do not set every row text y directly to `itemY`.

Regression test:

```text
test/select-hit-target.test.mjs
```

### Round-Screen Left Safe Area

Round-screen Select Activity has a curved visible edge on the left. Icons cannot sit too far left.

Key file:

```text
page/select/select.r.layout.js
```

Regression coverage checks that the category icon is inside the visible circular safe area.

### Zepp IMG Cropping

In this simulator, Zepp `IMG` crops when the resource is larger than the widget box. It does not automatically scale down.

Relevant test:

```text
test/select-hit-target.test.mjs
```

Test name:

```text
uses native-size icon resources so Zepp IMG widgets do not crop them
```

### Session Exercise Scale

Different B-style source poses have very different visible alpha bounds. Example: `sidelunge` is much wider than `legswing`. The animation generator normalizes visual scale; do not remove that logic.

Regression test:

```text
test/animation-scale.test.mjs
```

### Left And Right Exercise Sides

Single-side exercises must show different left/right directions. Do not load the same animation direction for both sides.

Relevant files:

page/session/session.js
