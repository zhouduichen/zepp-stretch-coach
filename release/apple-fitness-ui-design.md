# Stretch Coach 苹果运动风 UI 设计方案

## 设计目标

把当前界面从“网页菜单感”调整为“手表上的运动教练 App”：深色、克制、清爽，有明确数据主视觉。界面优先服务训练启动、运动选择和训练中的状态判断，不堆内容，也不使用夸张装饰。

## 整体布局

- 主页采用三层结构：品牌标题、两张数据卡、三枚核心操作按钮。
- 选择页采用滚动列表结构：顶部标题、分类标题、圆角运动行卡片。可见卡片负责视觉层级，透明点击热区负责交互命中。
- 训练页采用垂直专注结构：动作名、侧边提示、巨大倒计时、动作素材、底部暂停按钮。
- 完成页采用轻量反馈结构：完成标题、完成图标、恢复提示、返回按钮。
- 所有页面都保留圆屏安全边界，左侧图标和文字不贴边，底部按钮不压住圆角边缘。

## 颜色系统

- 背景：`#050806`，接近黑色但带轻微绿色调，避免纯黑的廉价感。
- 卡片：`#141a15` 到 `#1e251f`，用于暗色层级。
- 描边：`#485446` 的低透明版本，只做边缘分层，不做强边框。
- 主强调色：`#b6f640`，用于目标、分类和主要动作。
- 辅助强调色：`#6febae`、`#58b1ff`、`#ff5b81`，用于进度环、趋势线和运动数据点。
- 弱文字：`#9aa497`，用于说明、时长、完成摘要。
- 危险/暂停：`#ff5860`，只用于暂停和结束相关操作。

## 字体与信息层级

- 字体风格按 San Francisco 思路处理：干净、紧凑、数字醒目。Zepp 环境中使用系统字体能力，生成 PNG 文本使用 `Segoe UI Semibold` 作为接近替代。
- 标题清晰但不过大，避免首页标题压住内容。
- 数字使用大字号：主页目标百分比和训练倒计时是最强信息。
- 说明文字降低对比度，减少噪声。
- 按钮文字短化：`START`、`GUIDE`、`VIBRATION`，让按钮像手表原生控件，不像网页 CTA。

## 组件规范

- 背景：由生成器绘制静态运动氛围图，使用细弱环形光线和柔和暗色渐变，不再复制旧的复杂背景图。
- 数据卡：主页新增 `card_progress.png` 和 `card_trend.png`。卡片有圆角、柔和阴影、细描边和少量运动图形。
- 进度环：目标卡右侧显示绿色进度环和玫红端点，左侧叠加动态百分比。
- 趋势图：训练统计卡右侧显示蓝色折线和多色节点，左侧叠加累计训练次数。
- 列表行：选择页使用 `row_card.png` 作为可见圆角行卡，避免方块列表感。
- 按钮：主按钮使用荧光绿到薄荷绿渐变，次按钮使用暗色卡片面，危险按钮使用红色弱填充和描边。
- 图标：运动图标统一使用主强调绿，尺寸必须与布局一致，避免裁切。

## 页面细节

### 主页

- 顶部标题居中，副标题弱化。
- 数据区放在标题下方，双卡并排：左侧目标完成度，右侧训练总数和趋势。
- 三个操作按钮居中纵向排列，优先级为开始、指南、震动设置。
- 完成摘要收进 `Sessions` 数据卡，不再保留底部调试感文案。

### Select Activity

- 分类标题使用主强调色，表示当前运动类型分组。
- 每个运动项是独立圆角暗色卡片，左侧是运动图标，中间是名称和预计时长，右侧是 `Quick` 或 `Full`。
- 图标、文字、标签之间保留固定间距，避免错位和重叠。
- 行卡片使用低透明点击热区覆盖，视觉和交互分离。

### Session

- 训练页保持低干扰，动作素材是视觉中心。
- 倒计时用最大字号，进度和侧边提示弱化。
- 侧边提示使用绿色，表示动作方向或准备状态。
- 暂停按钮使用小型圆形红色控件，放在底部中心。

### Complete

- 完成页保留简单庆祝反馈，不加入复杂统计，避免训练结束时信息过载。
- 后续可以加入单张总结卡：本次时长、完成动作数、今日目标贡献。

## 微交互动效建议

- 主页进入时：标题先出现，数据卡从下方轻微滑入，按钮依次淡入。
- 进度环：从 0 度绘制到当前百分比，时长 500 到 700 毫秒。
- 数字：百分比和训练次数从 0 递增到目标值，时长约 600 毫秒。
- 按钮点击：按下时缩小到 0.97，松开恢复，背景亮度略升。
- 选择页滚动：行卡轻微视差或透明度递增，但不要影响滚动性能。
- 训练页倒计时：每秒数字切换时做极轻的缩放回弹，最后 3 秒使用红色或玫红提示。

## 实现约束

- 不引入新的 UI 框架，继续使用 Zepp OS 原生 widget 和生成 PNG 资产。
- 视觉复杂度放在 PNG 生成器中，页面代码保持简单。
- 新增视觉资产必须进入 `scripts/validate-assets.mjs`，避免模拟器漏上传。
- 所有布局必须同时维护 `gt.r` 和 `gt.s`。
- 运动素材继续使用 `resources/symbols` 的 B-style 姿态，不回退到旧素材。
