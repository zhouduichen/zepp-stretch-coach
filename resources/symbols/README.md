# Stretch Symbol Source Library

This folder stores the B-style flat source sprites for stretch movements.

## Visual Description

The style is recovered from `quad-source.png` and the original
`tmp/symbol-prototypes/style-board-v2-flat.png` board:

- 320x240 transparent PNG source sprite.
- Faceless lime/yellow-green human figure on transparent background.
- Smooth rounded silhouette with simple darker green inner shading.
- One soft orange/yellow-orange target muscle patch.
- No labels, arrows, skeleton lines, clothing detail, equipment, floor, or UI.
- Intended for watch-size exercise symbols and static muscle pulse previews.

## Generator

`scripts/generate-b-style-previews.ps1` is the generator for this style.

It expects a 1536x1024 style board arranged as 3 columns by 2 rows. Each board
cell is cropped with the fixed tile rectangles in the script. The generator then
keeps green body pixels and orange muscle pixels, makes the rest transparent,
saves a centered `resources/symbols/<id>-source.png`, and creates 12 preview
frames under `tmp/symbol-prototypes/b-style/<id>/`.

Runtime animation frames are generated by `scripts/generate-b-style-animations.ps1`.
For single-side exercises it emits both `<prefix>_left` and `<prefix>_right`
folders; the right-side frames are horizontal mirrors of the B-style source.

Example:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\generate-b-style-previews.ps1 `
  -Source .\tmp\symbol-prototypes\style-board-v2-flat.png `
  -OutputRoot .\tmp\symbol-prototypes\b-style `
  -SymbolRoot .\resources\symbols
```

For continuation boards, pass the 6 cell IDs in board order:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\generate-b-style-previews.ps1 `
  -Source .\tmp\symbol-prototypes\style-board-v2-lower-recovery.png `
  -OutputRoot .\tmp\symbol-prototypes\b-style `
  -SymbolRoot .\resources\symbols `
  -TileIds calf,glute,seated_hamstring,backtwist,chest,neck
```

## Boards Used

- `tmp/symbol-prototypes/style-board-v2-flat.png`:
  `quad`, `hamstring`, `hipflexor`, `sidelunge`, `shoulder`, `catcow`
- `tmp/symbol-prototypes/style-board-v2-lower-recovery.png`:
  `calf`, `glute`, `seated_hamstring`, `backtwist`, `chest`, `neck`
- `tmp/symbol-prototypes/style-board-v2-upper-joints.png`:
  `triceps`, `lat`, `bicep`, `wrist`, `groin`, `ankle`
- `tmp/symbol-prototypes/style-board-v2-dynamic.png`:
  `legswing`, `sidelegswing`, `walking_hamstring`, `hipcircle`,
  `torsotwist`, `armcircle`
